# Contributing to AI Scanner (Kotlin + Gemini)

First off, thank you for taking the time to contribute! 🎉 

Whether it's bug reports, feature requests, documentation improvements, or code contributions, all help is very much appreciated.

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the app, please open an issue and include:
* Your device / Android version.
* Steps to reproduce the issue.
* Expected vs. actual behavior.
* Logcat output if applicable.

### Suggesting Enhancements
Have an idea to make the AI scanner better? Open an issue with the label `enhancement` and describe your idea clearly.

### Pull Requests (PRs)
1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add some amazing feature'`).
4. Push to the branch (`git origin push feature/amazing-feature`).
5. Open a Pull Request.
